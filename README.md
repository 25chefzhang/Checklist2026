# 工作任务清单 — 微信小程序

基于微信小程序的智能工作任务管理工具，支持语音/剪贴板录入、定时语音提醒、浮动快捷入口、4 个月数据持久化。

## 快速开始

### 1. 环境准备

- 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 注册微信小程序 AppID（或使用测试号）

### 2. 打开项目

1. 在 Windows 端用微信开发者工具打开本项目目录
2. 导入时选择 `miniprogram/` 作为小程序根目录
3. 填写 `project.config.json` 中的 `appid`

### 3. 开通云开发

1. 在开发者工具中点击「云开发」图标
2. 开通云开发环境（基础版免费额度即可）
3. 复制云环境 ID，替换 `miniprogram/app.js` 中的 `'your-env-id'`

### 4. 创建数据库集合

在云开发控制台 → 数据库中创建以下集合：

| 集合名 | 说明 |
|--------|------|
| `tasks` | 任务主表 |
| `reminders` | 提醒记录 |
| `settings` | 用户设置 |
| `clipboard_logs` | 剪贴板历史 |
| `chat_tasks` | 群聊解析缓存（parseChatMessage 写入） |

### 5. 上传云函数

右键 `cloudfunctions/` 下的每个函数文件夹 → 上传并部署

### 6. 配置定时触发器（可选）

在云开发控制台 → 云函数 → checkReminders → 触发器 → 添加定时触发器
- 触发周期：每 5 分钟
- Cron: `0 */5 * * * * *`

### 7. 配置订阅消息（可选，后台补推）

订阅消息的作用：当用户**不在小程序前台**时，在截止时间点补一条后台推送。
（前台每 N 小时/每半天的循环提醒由小程序前台轮询引擎负责，无需订阅消息。）

> 微信订阅消息是「一次性」的：用户每次在小程序内授权一次，只能换取一条推送。
> 无法靠订阅消息实现「每 2 小时自动后台推送」。

配置步骤：

1. **申请模板**：微信公众平台 → 功能 → 订阅消息 → 选用/申请一个模板。
   建议模板字段：任务内容（thing）、提醒时间（time 或 date）、备注（thing）。

2. **前端填模板 ID**：把模板 ID 填入 `miniprogram/config.js` 的 `SUBSCRIBE_TEMPLATE_ID`。
   填好后，用户在「确认添加」带提醒的任务时会自动请求一次订阅授权。

3. **云函数配模板 ID**：云开发控制台 → 云函数 → `checkReminders` → 配置 → 环境变量，
   新增 `TEMPLATE_ID`，值填同一个模板 ID。（改环境变量无需重新部署代码）

4. **核对模板字段**：打开 `cloudfunctions/checkReminders/index.js`，
   确认 `data` 里的字段 key（`thing1`/`date2`/`thing3`）与你申请的模板字段一致，不一致就改。

5. **配置定时触发器**：云开发控制台 → 云函数 → `checkReminders` → 触发器 → 添加定时触发器
   - 触发周期：每 5 分钟
   - Cron：`0 */5 * * * * *`

6. **重新上传部署** `checkReminders` 云函数。

> 若只想用前台响铃/弹窗提醒（不需要后台推送），本节可全部跳过，
> 不填模板 ID 时云函数会自动跳过发送，不影响前台提醒。

### 8. 编译运行

点击「编译」，在模拟器或真机预览中调试。

> 语音功能需要在真机上调试，模拟器不支持录音。

## 语音智能录入与频率提醒（新）

通过语音（或手动/剪贴板文本）录入任务时，小程序会自动识别三要素：

| 要素 | 示例 | 结果 |
|------|------|------|
| 任务内容 | "明天下午三点开会" | 内容：开会 |
| 时间 | "下午三点" / "两小时后" / "周五下午两点" | 截止日期 + 具体时刻 |
| 紧急程度 | "紧急" / "加急" / "尽快" / "不着急" | 优先级 |

紧急度会自动映射为提醒频率：

| 紧急度 | 提醒频率 |
|--------|----------|
| 🔴 紧急（urgent） | 每 2 小时 |
| 🟠 高（high） | 每半天（12 小时） |
| 🟡 中（medium） | 每天（24 小时） |
| 🟢 低（low） | 截止前每日提醒一次 |

> 提醒依赖小程序前台运行（前台每 60 秒轮询 + 响铃/弹窗）。微信小程序后台定时推送受订阅消息限制，无法长期每 2 小时后台推送。

### 语音识别后端（二选一，自动降级）

小程序按以下顺序选择语音识别方式：

1. **微信同声传译插件 WechatSI（默认，免费）**
   - 已在 `app.json` 声明插件（provider `wx069ba97219f66d99`）。
   - 需在微信公众平台「设置 → 第三方设置 → 插件管理」中添加「微信同声传译」插件（公开插件，免费，一键添加）。
   - 仅真机可用，实时识别。

2. **腾讯云 ASR（云函数降级，可选）**
   - 当插件不可用时，自动降级为「原生录音 → 上传云存储 → recognizeVoice 云函数」。
   - 需开通腾讯云「语音识别 ASR」服务，并在云开发控制台给 `recognizeVoice` 云函数配置环境变量 `TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY`。
   - 云函数依赖已写入 `cloudfunctions/recognizeVoice/package.json`（`tencentcloud-sdk-nodejs`），重新上传部署即可。

两种后端都不可用时，语音识别返回空，会提示用户手动输入（不影响其它功能）。

## 群聊任务提取 — 使用方式

### 方式一：复制群聊消息（推荐）

1. 在微信群聊中，长按包含任务的消息 → 复制
2. 打开 Checklist2026 小程序
3. 小程序自动读取剪贴板，识别到任务关键词后弹窗询问
4. 如果复制了多条消息（群聊记录转发格式），自动拆分为多个任务供逐条确认

### 方式二：转发聊天记录到小程序

1. 在微信群聊中长按消息 → 多选 → 转发 → 搜索"工作任务清单"小程序
2. 小程序接收后自动识别任务内容

### 识别能力

小程序能识别以下群聊消息模式：

- **@指派**：`@张三 完成需求文档` → 任务 + 负责人
- **【标签】**：`【紧急】【任务】修复线上bug` → 高优任务
- **#话题#**：`#本周QA# 提交测试报告` → 带分类的待办
- **DDL/日期**：`周五前提交周报`、`deadline：6月30日` → 自动设定截止日
- **指派句型**：`你来处理这个`、`你负责跟进`、`交给你了`
- **检查/验收**：`确认一下这个方案`、`看下那个问题`
